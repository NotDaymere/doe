# Doe

Frontend React project based on [Vite](https://vitejs.dev/) and [Ant Design](https://ant.design/), featuring TipTap, Apollo GraphQL, PDF viewing, Monaco Editor, and more.

## 🔧 Requirements

Before you begin, make sure your development environment meets the following requirements:

- **Node.js**: v18.x or higher
- **npm**: v9+
- **Git**: Required for cloning the repository.
---

✅ Tip: You can check your installed versions with:

```bash
node -v
npm -v
git --version
````


## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/NotDaymere/doe.git
cd doe
```
## ⬇️ Install dependencies
```bash
npm install --force
```
## 🚀 Start the app
```bash
npm start
```
This starts the local dev server at:
http://localhost:5173

⚙️ Note: The "proxy" is set to http://127.0.0.1:1337 in package.json, so make sure the backend is running at this address (e.g., a NestJS API).

## 🛠 Build
```bash
npm run build
```
Production-ready files will be generated in the dist/ folder.

## 🧱 Stack

React 18

Vite

Ant Design 5

Apollo Client + GraphQL

TipTap Rich Text Editor

PDF / DOCX / XLSX render support

Charts: D3, Recharts, Google Charts

Monaco Editor

Zustand for state management


## 📦 Key Technologies Used

- **React / React DOM** – UI rendering
- **Vite** – Fast bundler and dev server
- **Zustand** – Global state management
- **React Router DOM** – Client-side routing
- **Ant Design** – Component library for fast UI development
- **Ant Design Charts** – Built-in charting components
- **Classnames / clsx** – Conditional class utilities
- **Apollo Client** – GraphQL client
- **GraphQL** – Query language for APIs
- **Tiptap** – Rich text editor based on ProseMirror
- **Monaco Editor** – Code editor (VSCode engine)
- **Highlight.js** – Syntax highlighting
- **React PDF / PDF-lib** – PDF rendering and generation
- **XLSX / PapaParse** – Excel and CSV support
- **Recharts / D3** – Data visualization
- **Wavesurfer.js** – Audio visualization and recording
